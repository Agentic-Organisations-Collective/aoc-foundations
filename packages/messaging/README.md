# messaging

Canonical verbal identity of the Agentic Organisations Collective — the reusable
core texts that appear across more than one surface: the website hero, LinkedIn and
other social bios, and press boilerplate. The verbal counterpart to `brand-kit`
(visual identity).

Kept as a shared building block so every channel references **one** wording instead
of maintaining its own copy. Bilingual: German and English are kept in sync.

## Contents

- `messaging.md` — the canonical strings: name, claim, hero title, and abstract/boilerplate (DE + EN).
- `issues.md` — open normalization/review points (kept out of the content file).

## Consumers

- **Website** (`aoc-website`) — home hero eyebrow/title/subtitle; published into the site's live content.
- **Social** (`aoc-communications/social-posts`) — profile bios, the short abstract on LinkedIn.
- **Press** (`aoc-communications/press`) — the "About the collective" boilerplate at the end of releases.

## Governance

Shared read across repos. Changes to the canonical wording are a deliberate editorial
decision; consumers reference this text rather than diverging from it.
