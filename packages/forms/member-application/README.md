# forms/member-application

Reusable template for the membership application form. Contains the blank form structure and its field definitions. Submitted applications are stored board-only, not here.

[`fields.md`](./fields.md) is the canonical field list. The public web form, the application issue template in `aoc-board`, and § 3 of the membership admission rules all derive from it, so a field is added or changed there first.
